# Overview

A fairly empty Drupal theme to use for teaching simple Drupal concepts.

## Starting

Nothing to do, just install the theme.

## CSS

CSS is in /src/css. The style.css file in /dist is what we load for our theme. Imports of all CSS files into this file are for temporary demonstration purposes; it is not advisable to use imports of CSS partials in a production-ready theme.

## Images

Logo and screenshot are in /dist/images.
